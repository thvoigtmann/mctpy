Implemented models 
------------------

For a list of individual features, see below. The modularity of `mctpy` allows
many combinations of models and structure factors and things being
calculated. The following table is deliberately restricted to those things
that have been explicitly tested and that are deemed reliable.

(Legend: NEP = nonergodicity parameters; evals = eigenvalues (critical amplitudes);
BD = Brownian dynamics; ND = Newtonian dynamics; damped ND = damped Newtonian dynamics;
G = shear modulus; M = longitudinal modulus; cc = interdiffusion kernel)

Note that you can get an overview of the various models and structure factors
that are implemented using

  .. code-block:: python

    import mctpy as mct
    # list solvers: correlator, nonergodicity_parameter, etc.
    mct.__h5__.Factory._registry.keys()
    # list models:
    mct.__h5__.ModelFactory._registry['model'].keys()
    # list structure factors:
    mct.__h5__.ModelFactory._registry['structurefactor'].keys()


Implementation status
---------------------

The following is a list of features of the `mctpy` code that are currently being
implemented, some of them at the end rather aspirational. (The two-time code will
not be part of public production code for a while yet.)

The dates indicate when the code base was first implemented, in the old
`MCTsolver` C++ code (colloquially known as "Der Kraken" and made available
to some research groups in the past - this is only for historic reasons),
and in the current `mctpy` code.

For production runs, rely on versions no earlier than the one quoted
in the "stable version" column.
